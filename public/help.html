词环 LexiLoop

一款轻量、离线可用的英语单词循环记忆工具

词环是一个纯前端单词学习应用，无需注册、无需联网（首次加载后），数据保存在浏览器本地。它通过多种学习模式帮助你高效记忆英语词汇。

功能特色

  • 多词书支持，按难度分级
  • 卡片翻转学习，支持英美发音
  • 发音支持在线或离线、自动识别
  • 记不住怎么办：洗脑模式
  • 蚕食模式：卡片趣味消消乐
  • 列表模式：自动发音、自动背诵
  • 考试模式：听音选词，检验记忆
  • 错题本：自动收集错题，间隔复现
  • 学习统计：可视化进度追踪
  • 深色/浅色主题，跟随系统
  • 数据本地存储，隐私安全

卡片学习

卡片模式是最基础的学习方式。每次展示一个单词，点击卡片翻转查看中文释义。支持自动发音，可切换美音/英音。

  • 点击卡片翻转查看释义
  • 点击 🔊 按钮重听发音
  • 左右滑动或点击箭头切换单词
  • 听完读音标记为"已学"
  • 支持开始洗脑模式

蚕食模式

蚕食模式类似消消乐，点击某单词，会自动发音，当前卡片就如何蚕一样被吃掉了，相当于你已学习过这个单词了。适合休闲、无聊时，或通勤等场景。每消除一批、会自动加载下一批、至到学完为止。

  • 点击某卡片单词
  • 可在设置中调整蚕食速度（卡片消失延时时间）
  • 支持"纯英语"或"英语+中文"朗读模式
  • 可设置一次加载多少个卡片
  • 支持开始洗脑模式

列表浏览

列表模式以表格形式展示当前词书所有单词，方便快速背诵和浏览。

  • 点击开始即可以背诵
  • 自动下一个单词
  • 点击单词行可发音
  • 已学单词会有标记
  • 记录学习次数
  • 支持开始洗脑模式

考试模式

从已学单词中出题，播放单词发音后，需要同时选出对应的英文和中文。答对自动通过，答错加入错题本。

  • 考试必须先学习单词 3 个以上
  • 听发音 → 左列选英文 → 右列选中文
  • 两列都选对才算通过
  • 首次通过会有 🎉 烟花效果
  • 错题会按间隔自动复现

错题本

考试中答错的单词会自动收入错题本。错题本默认收起，点击标题展开查看。系统会在后续考试中按间隔自动穿插错题，帮助巩固薄弱词汇。

  • 显示每个错词的错误次数和正确次数
  • 错题会在考试中每隔 3~5 题自动复现
  • 答对后逐步减少出现频率

已学习

已学习页面展示当前词书中所有已查看过的单词列表，可按学习次数、通过状态和错误次数及排序。

统计

统计页面展示当前词书的学习进度，包括已学数量、已通过数量、累计学习次数等数据的可视化图表。

顶部工具栏

进入词书学习后，顶部工具栏提供以下快捷功能：

🔁 洗脑模式

开启后，每个单词会连续朗读 3 次，适合需要反复强化听觉记忆的场景。

朗读内容

可选择"纯英语"或"英语+中文"两种朗读模式：

  • 纯英语：只朗读英文单词
  • 英语+中文：先读英文，再读中文释义

顺序/随机

顶部标签显示当前学习顺序，可在设置中切换顺序或随机模式。

设置

点击右上角 ⚙ 齿轮图标打开设置面板：

  • 主题：跟随系统 / 浅色 / 深色
  • 顺序：顺序学习 / 随机学习（可重置随机序列）
  • 发音口音：美音 / 英音
  • 语速：0.5x ~ 1.5x 可调
  • 蚕食速度：自动播放间隔时间
  • 自动发音：翻卡时是否自动朗读
  • 中文朗读：读第一个意思 / 读所有意思
  • 清空学习记录：重置当前词书进度（不可恢复）
